# Лабораторная работа №1

## Анализ временной сложности элементарных алгоритмов

**Вариант:** 20  
**Seed:** 50

---

## Состав работы

- `lab01-complexity-starter.py` — реализация алгоритмов
- `report.md` — отчёт
- `lab01_loglog.png` — график степенных алгоритмов
- `lab01_binary_pow.png` — график бинарного возведения в степень

## Реализованные алгоритмы

1. **Сумма элементов массива** — O(n)
2. **Поиск максимального элемента** — O(n)
3. **Подсчёт пар равных элементов** — O(n²)
4. **Бинарное возведение в степень** — O(log n)

## Запуск

Генерация данных:
```bash
python ../scripts/generate_data.py --variant 20 --only arrays
```

Запуск работы:
```bash
python lab01-complexity-starter.py --variant 20
```

## Результаты

Все экспериментальные наклоны совпали с теоретическими оценками:
- array_sum: наклон ≈ 0.97 (теория: O(n))
- array_max: наклон ≈ 1.03 (теория: O(n))
- count_equal_pairs: наклон ≈ 2.00 (теория: O(n²))
- binary_pow: O(log n) подтверждено графиком t(log₂ n)

Подробный анализ см. в `report.md`.
