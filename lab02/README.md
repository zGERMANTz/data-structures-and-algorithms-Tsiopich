## Реализованные компоненты

### 1. Рекурсивные функции
- `factorial(n)` — O(n)
- `fib_naive(n)` — O(2^n)
- `fib_memo(n)` — O(n) с мемоизацией
- `hanoi(n)` — O(2^n), Ханойские башни

### 2. DynamicArray
Динамический массив с ручным управлением ёмкостью:
- Рост ×2 при достижении capacity
- Сжатие ×2 при заполнении ≤ 1/4
- Амортизированная O(1) для append

### 3. Stack (LIFO)
Стек на базе DynamicArray через публичный интерфейс

### 4. Deque (двусторонняя очередь)
Дек на базе двусвязного списка, все операции O(1)
